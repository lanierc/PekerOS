# PekerOS Geliştirme Yol Haritası

## 🟢 Faz 0: Temel Altyapı (Tamamlandı)
- [x] GDT (Global Descriptor Table) kurulumu
- [x] IDT (Interrupt Descriptor Table) kurulumu
- [x] ISR & IRQ mekanizması
- [x] PIC (Programmable Interrupt Controller) Remapping
- [x] Klavye Sürücüsü (Türkçe Q desteği)
- [x] PIT (Programmable Interval Timer) - 100Hz
- [x] VGA Metin Modu Sürücüsü (Kaydırma, Renk desteği)
- [x] Temel Shell (fash v0.1)

---

## 🟡 Faz 1: Bellek Yönetimi (Sıradaki Hedef)
- [x] **Fiziksel Bellek Yöneticisi (PMM)**
    - [x] Multiboot bellek haritasını (mmap) okuma
    - [x] Bitmap tabanlı sayfa takibi (4KB bloklar)
    - [x] `alloc_frame()` / `free_frame()` fonksiyonları
- [ ] **Sanal Bellek & Sayfalama (Paging)**
    - [x] Page Directory ve Page Table kurulumu
    - [x] Bellek koruma (Read-only / Supervisor)
    - [x] Higher Half Kernel (Kernel'ın 3GB+ adresine taşınması)
- [x] **Dinamik Bellek (Kernel Heap)**
    - [x] `kmalloc()` ve `kfree()` implementasyonu

## 🟢 Faz 2: Depolama ve Dosya Sistemi (Tamamlandı)
- [x] **ATA/IDE Sürücüsü**
    - [x] LBA 28/48 bit modunda disk okuma/yazma desteği
- [x] **Dosya Sistemi (PAFS)**
    - [x] Özel PAFS mimarisinin tasarımı (Superblock, Inode, Block)
    - [x] RAM tabanlı Sanal Disk implementasyonu
    - [x] Dosya oluşturma, okuma, yazma
- [x] **Shell Geliştirmeleri**
    - [x] `ls`, `cat`, `touch`, `write` komutlarının eklenmesi
    - [x] Komut geçmişi (History)

- [x] **Kullanıcı Modu (Ring 3)**

- [x] **Sistem Çağrıları (Syscalls)**
    - [x] `int 0x80` mekanizması
